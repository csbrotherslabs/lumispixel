Fix Common Problems

Start with the issue you are experiencing and follow the recommended checks.

I Cannot Sign In

  • Confirm the email address
  • Reset the password
  • Verify the account
Troubleshoot Issue

My Photos Will Not Upload

  • Review supported formats
  • Check file size
  • Confirm internet stability
Troubleshoot Issue

A Gallery Will Not Publish

  • Review required gallery fields
  • Confirm image processing
  • Check visibility settings
Troubleshoot Issue

A Client Cannot Access a Gallery

  • Confirm the gallery link
  • Review password settings
  • Check expiration settings
Troubleshoot Issue

Photo Search Is Missing Results

  • Use a clearer selfie
  • Confirm gallery availability
  • Review privacy or consent settings
Troubleshoot Issue

AI Processing Is Taking Longer Than Expected

  • Confirm upload completion
  • Review processing status
  • Check collection size
Troubleshoot Issue

Billing or Payment Failed

  • Confirm payment details
  • Review bank authorization
  • Check billing address
Troubleshoot Issue

The Website Does Not Display Correctly

  • Refresh the preview
  • Review theme settings
  • Confirm content completion
